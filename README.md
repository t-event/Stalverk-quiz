# Stålverket – Smelteprøven 🔥

Et quizspill for å lære stålverket, fra skraplageret til strengen. Spørsmålene er laget ut fra metallurgikurs-kompendiet (Celsa, 2. utg. 2024). Selve kompendiet ligger **ikke** i repoet.

## Slik spiller du
Åpne `index.html` i nettleseren. Det trengs ingen installasjon. Spillet fungerer også med GitHub Pages.

- **15 stasjoner** i prosessrekkefølge, med til sammen ca. 260 spørsmål. Hver stasjon starter med huskeregler.
- **Flere spørsmålstyper:** flervalg, sant/usant, regnestykker (B2, B3, CE2, temperaturfall) og «sett i rekkefølge».
- **3 elektroder (liv)** per runde. Stjerner etter treffsikkerhet, og rang fra *Lærling i skraplageret* til *Stålverksmester*.
- **⚡ Lynrunde** (60 sek.), **🏆 Sluttprøven** (20 blandede spørsmål) og **🔁 Øv på feilene**.
- Hver forklaring viser til sidetallet i kompendiet. Fremgangen lagres i nettleseren.

Spørsmålene ligger i `questions.js` og er enkle å redigere eller utvide.
